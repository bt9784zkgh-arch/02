# test-report: choice-maze（せんたくの めいきゅう）

- チェック担当: game-tester（チーム02）
- 日付: 2026-11-18
- 方法: Playwright 1.63 + Chromium（headless、`file://` で開く、deviceScaleFactor 2）
  - 通し1: 1920×1080 マウス。各場面でDを先に選び、A・B・Cも「みる」で全部見て、まとめでD（84枚の未来カードを全部読んだ）
  - 通し2: 1280×720 マウス。まとめでD以外を3回選ぶ（全7場面のうち6場面）。s3-2 は「この ばめんを とばす」
  - 通し3: 1280×720 キーボードだけ（Enter と 1〜4 キー）
  - 通し4: `--disable-webgl --disable-3d-apis` で最後まで
  - ほかに: AudioContext の出口に AnalyserNode をはさんで音量（RMS）を測定。3D層だけを見える状態にしてフレームの差分を比較
- 読みかえ（依頼どおり）: 「正解だけで最後まで」→ 各場面でおすすめの道Dを選び、まとめでもDを選ぶ。「3回まちがえても」→ まとめでD以外を3回選ぶ（ヒント → DとBにしぼる → いっしょに確かめる）

## 直すべき点（担当名つき）
1. **game-builder**: ふり返り2/2 の見出し `'3（さん）びょう まって かんがえる コツ'` が `rb()` を通っておらず、「（さん）」がかっこのまま出る → `rb('3（さん）びょう まって かんがえる コツ')` にする（game.js showReview の page 2）。
2. **game-builder**: ふり返り1/2 に設計書の「みた みらい」（見た1しゅうかんごカードを小さく並べる）を足す。数の文は「Nつの みちを みたよ」にそろえる。
3. **game-builder**: 重なりを直す。(a) ほめことば・ヒントの布（`.cm-praise, .cm-hint`）がカードのランプの列にかぶらないよう、`.is-sum` のときカードの高さを少し下げるか、布をカードの下にずらす。(b) s3-2 で「とばす」が出ているとき、えらぶ画面とまとめの画面の吹き出しがカードにかぶらないようにする（吹き出しの max-width をしぼる、または `.cm-choices` の下に余白をとる）。
4. （小さいこと）**game-builder／art-director**: `assets/img/home.jpg` の権限を 644 にする。使っていない `fonts/*-japanese-*.woff2`（4.8MB）を消す。
5. （提案。×ではない）**lesson-designer／art-director**: 相手の顔は design.md の表どおりだが、表は道ごとに決まっているので文と合わない所がある（例: s2-1 B 3びょうご「がっかり」が ふつう顔、s2-3 C 3びょうご「かなしい」が ふつう顔）。先生の確認のときに、未来1枚ごとに mood を指定できるようにするか検討する。
