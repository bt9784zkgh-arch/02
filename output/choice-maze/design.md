## 1. テーマ: 「じゅうたん模様の迷宮」

ホーム画像の世界（紺のじゅうたんと赤のじゅうたんが、金色の道で X 字に分かれる）を、そのまま遊ぶ画面に持ちこむ。

- **地（背景）**: 夜の紺。まわりの縁にだけじゅうたん模様（ひし形）を置き、まんなかは無地にする。問題エリアに模様を入れない。
- **紙（カード）**: 生成り色の布。金糸の点線ステッチをふちに入れる。じゅうたんと同じく、端に**房（ふさ）**をつける。
  - 選択カード = 小さいじゅうたん（下に房）
  - 未来カード = 横長の廊下じゅうたん（左右に房）
  - 説明・ほめことば = 房なしの布
- **道**: 金色の帯。地図とタイムラインは「金の道の上を進む」形にする。
- **ランプ**: 金の油ランプ（アラジンのランプの形）。「みらいの ランプ」と、できたことの目じるしに使う。
- **案内役「ひかりさん」**: 金色の光の玉（`assets/svg/hikari.svg`）。ホーム画像で子どものうしろに光っている輪を、キャラクターにしたもの。

いちばん目立たせるのは**房のついたじゅうたんカード**だけ。ほかの部分（文字、ボタン、上と下の帯）は静かに、同じ形のくりかえしにする。

使わないもの: 紫や青のグラデーション、ネオンの光、すりガラス、絵文字、同じ角丸と同じぼかし影のカードの並び。
- ボタンの影はぼかさない（墨色で 8px 下にずらした「厚み」）。
- 角丸は使う場所で変える: じゅうたんは 6px、ボタンは 20px、丸いものは円。

## 3. 文字

| 役わり | 書体 | 太さ | 大きさ |
|---|---|---|---|
| 本文・カード・ボタン | **Zen Maru Gothic**（丸ゴシック） | 500 / 700 | 本文 32px、カードの文 32px、未来カードの文 36px |
| 問題文・場面の説明 | Zen Maru Gothic | 700 | **44px** |
| 見出し・タイトル・きもちの名前・「すって／はいて」 | **Klee One**（手書きの教科書体） | 600 | 64〜104px |
| いちばん小さい文字（ラベル・「みた」） | Zen Maru Gothic | 700 | **28px**（これより小さくしない） |

- 行間は 1.7（ルビが入るので広め）。ルビの文字は親文字の半分。
- フォントは `fonts/` に同梱している（woff2、SIL OFL。`fonts/fonts.css` を `style.css` が読みこむ）。ネットにつながっていなくても表示できる。
- 読みこめないときの代わり: BIZ UDPゴシック → ヒラギノ丸ゴ → メイリオ → IPA Pゴシック（`--cm-font-body`）。見出しは UDデジタル教科書体 → Zen Maru Gothic。
- **分かち書きのスペースでだけ折り返す**（`word-break: keep-all`）。ことばの途中では切れない。
- 見出しを大文字だけにしたり、一語だけ色を変えたりはしない。

## 4. 画面サイズとわく（全画面で同じ）

基準は 1920×1080。`.cm-stage` をまるごと拡大縮小する。1280×720 でも配置はくずれない（0.667 倍になる）。

```js
// game.js（読みこみ時と resize のとき）
function fitStage(){
  const s = Math.min(innerWidth / 1920, innerHeight / 1080);
  document.documentElement.style.setProperty('--stage-scale', s);
}
addEventListener('resize', fitStage); fitStage();
```

## 6. 効果音・演出のタイミング

| とき | 音（`Sound.play`） | 3D（`Motion3D`） | CSSの動き |
|---|---|---|---|
| タイトル表示 | （BGM待ち） | `setScene('title')`: 金のランプと房のついた小さいじゅうたん片が奥からゆっくり浮かぶ | なし |
| はじめる | `tap` ＋ `Sound.start()` | `setScene('play')` | ボタンが沈む |
| 3びょう まつ | なし（BGMはそのまま小さく） | 背景はほぼ止める | 円が8秒で大きく・小さく |
| カードを選ぶ | `tap` | なし | `.is-picked` の輪 |
| 未来カードを1枚めくる | `tap` | なし | 横にめくれる（0.4秒）。うごきを へらすときは入れかえるだけ |
| D の未来を見おえた | `correct` | `celebrate(x,y)`: 1しゅうかんごカードのランプの位置で、金の紙ふぶきを小さく（1秒） | ランプが1つずつ点く（0.3秒ずつ） |
| A・B・C の未来を見おえた | なし | なし | ランプが点く（同じ動き。責めない） |
| まとめで D を選んだ | `correct` | `celebrate(x,y)` | ほめる布が下から出る |
| まとめで D 以外（1〜3回目） | `retry`（やわらかい音。ブザー禁止） | `encourage()`: ひかりさんが首をかしげる | ヒントの布 |
| ステップクリア | `clear` | `await stepClear(n)`: 3Dのはんこが回って押される（2秒以内） | そのあとに `.cm-clear` を表示 |
| ふり返り | なし | `setScene('result')`: 集めたランプが並んで1つずつ灯る | なし |

- 点滅は1秒に3回まで。画面全体を光らせない。問題を解いているあいだ（5-4〜5-7）は、背景の3Dをほとんど止める。
- `Motion3D.init(document.getElementById('stage3d'), { theme })` の `theme` には、次をわたす。
  `{ colors: { navy:'#1E2747', red:'#8C2B22', gold:'#D2A03A', paper:'#F2E6CB', ink:'#2A211C' }, motif: 'carpet-lamp' }`
  （素材は紙と布。`MeshToonMaterial` を使い、金属の照り返しはつけない）
- `#stage3d` には `.cm-layer3d` をつけて、`.cm-stage` の中に置く（z-index 30、クリックを通す）。

### うごきを へらす
`<html data-motion="low">` にするか、OS で `prefers-reduced-motion` が有効なら次のようにする。
- 呼吸の円を止める。
- めくり・沈み・浮きの動きを止める。
- 3Dはふわっと出すだけにする。

game.js は設定の「うごき」ボタンで `data-motion` を切りかえ、同時に `Motion3D.setReducedMotion(true)` を呼ぶ。

## 8. イラストの仕様書（Python でプログラム描画 → PNG）

### 8-1 画風のルール
- **全体**: 絵本のような切り絵と手描き線。ホーム画像の「紺と赤のじゅうたん、金の道」の世界を、平らな面で描く（グラデーションを使わない、または2段階まで）。
- **パレット**（この色以外は使わない）

| 用途 | コード |
|---|---|
| 線 | 墨 `#2A211C` |
| 紙の地 | 生成り `#F2E6CB` ／ 影 `#E6D3AA` |
| じゅうたん紺 | `#1E2747` ／ 明るい紺 `#34406B` |
| じゅうたん赤 | 茜 `#8C2B22` ／ 明るい茜 `#B5493A` |
| 金 | `#D2A03A` ／ 金の墨 `#6B4A12` |
| はだ | `#EBCBA8` ／ ほお `#D98E7A`（不透明度 50%） |
| かみの毛 | `#3A2C25`（主人公）、`#5A4636`、`#2A211C` |
| 服の差し色 | 苔 `#5E7A5A`、灰青 `#6F7F99`、からし `#B8913A` |
| きもちの記号だけ | 灰 `#8A8580`（もやもや）、赤 `#C0392B`（いらいら）、青 `#3E6FA8`（かなしい のしずく） |

- **線**: 墨、1280px 幅の絵で 6px（640px 幅で 4px、512px の顔で 6px）。端と角は丸くする。線は**手描き風にゆらす**（点を 8〜12px おきに打ち、垂直方向に ±1.5px のノイズを足して、なめらかな曲線でつなぐ）。同じ形を2回描くときは、ノイズの種を変える。
- **紙の質感**: 全面に細かい粒のノイズ（明るさ ±4%、不透明度 6%）。画像の端から 24px は少し暗くする（`#E6D3AA` を 30%）。
- **じゅうたんの床**: 場面の床はすべてじゅうたんにする。
  - 左右に紺と赤を分けるか、紺と赤のひし形をくりかえす。
  - ひし形の中には金の墨で小さい花（4枚の花びら）を入れる。
  - 端には房（長さ 14px、間隔 9px、色は `#E6D3AA`、線は墨）をつける。
  - 床は画面の下 1/3 くらいにおさめ、人物より目立たせない。
- **人物（主人公）**: ホーム画像の子どもに寄せる。
  - **性別を決めない**。まつげ・リボン・スカート・ネクタイは描かない。
  - 頭は**まん丸**、肩までの短いボブ（`#3A2C25`）。目は墨の点2つ（直径は顔の幅の 6%）。口は線1本。鼻は描かない。
  - **フードつきの上着**（明るい紺 `#34406B`、フードは背中に下ろす）、生成りのズボン、墨のくつ。
  - 体は3頭身。手は丸、指は描かない。
- **ほかの人**:
  - 先生: 大人の背の高さ、まるいめがね、からし色のカーディガン。
  - 家の人: 苔色のエプロン。
  - ともだち: 灰青のパーカー、かみの形を変える。
  - なかま: 苔色のジャージ。
  - おとな（相談相手）: 先生と同じ。
  - どの人も性別を決めず、同じ丸顔で描く。
- **やってはいけないこと**: 文字を描かない（吹き出しの中も記号だけ）。数字を描かない。人をたたく絵、けがの絵、血は描かない。暗すぎる場面にしない。
- **構図**: 主人公はいつも画面の左〜中央に置き、こちらに体を向ける。相手は右側に置く。背景の物は3つまでにする。
