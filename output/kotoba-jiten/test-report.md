# テスト報告 — kotoba-jiten（ことばの じてんを つくろう）

チェック担当: game-tester ／ 2026-11-08
方法: Playwright＋Chromium（headless）。`file://` で index.html を開いた。1920×1080 と 1280×720 の両方で、全8ステージを正解だけで最後まで通した。ほかに、まちがい・キーボードだけ・音・うごき・WebGLなし・保存とつづきからを別々に試した。スクリーンショットは deviceScaleFactor 2 で 427枚（`screenshots/`）。

## 結論
**全8ステージとも、ふり返りまで止まらずに遊べる。** どのステージもじてんのページが全部うまる（20／16マス）。正解のカードは毎回1まいだけで、選べない問題もない。コンソールのエラーは0件（three r158 の deprecated 警告は数えていない）。
ただし、**文字が切れる・かくれる不具合が4つ**（×1〜×4）と、**ふりがなのない漢字が1か所**（×5）ある。直すのはどれも小さい。

## 直すべき点（担当名つき）

### ×1 カードの文の最後が切れて見えない（2か所）　→ **game-builder（game.js の LESSON）**
- 起きていること: `twoLine()` は半角スペースの所でしか改行しない。だから、スペースのない長いかたまりがあると1行目が入りきらず、ブラウザが3行目を作る。その3行目がかくれてしまう。
  - **MO01**「ぶつかったら「ごめんなさい」と 言う」: カード（S5 ステップ1 2問目・ステップ2おてほん）でも、じてんのマスでも「言う」が見えない（`1920x1080_s5_st1_q2.png`, `1280x720_s5_jiten_full.png`）
  - **OM13**「「なんで？」を「どうしたの？」に 変える」: カード（S3 ステップ1 3問目）でも、じてんのマスでも「変える」が見えない（`1920x1080_s3_st1_q3.png`）
- 直し方: game.js の LESSON に分かち書きのスペースを足す。
  - `MO01: ['ぶつかったら 「ごめんなさい」と {言|い}う', …]`
  - `OM13: ['「なんで？」を 「どうしたの？」に {変|か}える', …]`
  - あわせて、MO02 を `'{遅|おく}れて 「すみません」と {言|い}う'` にすると「言う」だけが2行目に残らなくなる（△）
  - 念のため、`twoLine()` で1行が `longAt`（15字）をこえるときに `.is-long` だけでなく警告を出すようにすると、先生が文を書きかえたときにも気づける（△）

### ×2 ステージ3で、想像の雲が場面の文の上にかぶる　→ **art-director（style.css）**、または **game-builder（game.js）**
- 起きていること: `.q-scene .thought { left:120px; top:-12px; white-space:nowrap; max-width:none }` の雲が、問題の帯の文の上に重なる。
  - ステップ3では場面の文が1行目に来るので、文がかくれる。S3-3-1 では「髪型を」の「髪」、**S3-3-3 では「友だちが 好きな アニメ」が全部**かくれる（`1920x1080_s3_st3_q1.png`, `_q3.png`）
  - ステップ2でも、問いの文「相手の」のふりがなに雲がかかる（`1920x1080_s3_st2_q1.png`）
- 直し方（どちらか一方）:
  - art-director: `.q-scene .thought` を場面の絵の箱の上（`top` をマイナス、帯の上にはみ出す向き）に出す。または `max-width` を決めて2行まで折り返す。あわせて、`.q-strip` の中で `.q-text` の左の余白を雲の分だけあける。
  - game-builder: ステップ3では `q.thought` を帯に出さない（`otehon3`・`showQuestion` の `if (st.thought) q.thought = …`）。設計書8章で雲を帯に出すのは「ステップ2」だけ。場面の文があるので、ステップ3では雲がなくても伝わる。

### ×3 ふり返りで選んだカードの文の2行目が切れる　→ **art-director（style.css）**
- 起きていること: `.review__pick .card { width:460px; height:380px; }` だと文の欄が80pxしかなく、2行のカードは2行目が下で切れる。
  - 「プリントを ／ もらって「ありがとう」」（`1920x1080_s4_review_picked.png`）、S3「落ちこんでいる…」、S8「係の 仕事を…」で起きた
- 直し方: `.review__pick .card` を問題画面のカードと同じ 500×424 にする。または高さを430px以上にする。絵の高さを少し小さくしてもよい。

### ×4 （小さい）おてほんのとき、上の進み具合の帯が設定ボタンの下にもぐる　→ **art-director（style.css）**
- 起きていること: おてほんの間は「いま **おてほん** ／ ぜんぶで 4問」が太字で長くなる。そのため `.progress` の右はしが 1393px になり、設定ボタン（左はし 1382px）の下に約11px入る（`1920x1080_s1_st1_0otehon.png`）。読むのにはこまらない。
- 直し方: `.progress` に `max-width`（右はし 1360px まで）をつける。または「おてほん」の文字を小さくする。

### ×5 「もどる」ボタンの「本だな」にふりがながない　→ **game-builder（game.js・index.html）**
- 起きていること: game.js 857行 `updateBack()` が `textContent = '本だな'` を入れている。index.html の最初の文字も「本だな」。play・じてん・ふり返りの全画面に出る。
- 直し方: `$('.btn-setting__state', setBack).innerHTML = … '<ruby>本<rt>ほん</rt></ruby>だな'` にする。または ひらがなの「ほんだな」にする。index.html の最初の文字も同じに直す。

### △6 （任意）ガイドの腕章の「図書」　→ **art-director（assets/guide*.svg）**
- 15px の飾り文字で、ふりがながない。読ませる文ではないが、約束の「ふりがな」に合わせるなら「としょ」にするか、文字を消して本の形のマークにする。

### △7 （任意）S5 ステップ3 3問目で「責め続ける」を2回えらんだとき
- 2回目も「もういちど 見てみよう。あやまれたなら、十分 がんばった」が出て、設計書のヒント「前を 向いているのは どれ？」が出ない（正解カードは光るので、進むのはこまらない）。→ game-builder: `miss()` の2回目は `c.retry` があっても `qd.hint` を出す（または2つをつなげる）。
