## 2. 直すべき点（担当つき・重い順）

1. **【motion-3d】`motion3d.js` の `MASCOT_POS.play`（599〜604行）**
   - がまぐちくん（x 1350, y 142, size 0.8）が「ぜんぶで ○もん」の右はしに かさなる。進みぐあいの文字は x 872〜1370。3Dの範囲は x 1313〜1410 なので、57px かさなる
   - HUD のすきま（文字の右はし 1370 〜 設定ボタン 1448）は 78px しかない。影をふくめた がまぐちくん（約100px）は 入らない
   - 案: 問題中の位置を、おみせの ひとの右・たなの上の あいたところに うつす（例 `play: { x: 480, y: 525, size: 0.8 }`）。ステップ2・3で 影が ねふだの「なまえ」に かからないかを 確かめる
   - ほかの案（art-director と game-builder）: `.hud` の かんばんの列を `minmax(520px, 680px)` にちぢめる。そして `.settings-space` を 約130px 広げて、がまぐちくんの すきまを とる
   - ふり返り（`result`）は HUD の真ん中が 空いているので、今の位置のままでよい
2. **【game-builder】`game.js` 30行 ステップ1問3 `dim: [10]`**
   - 設計書は「ほかの 2まいを うすくする」。50えんが うすくならない
   - 今でも 5えんに わくが出るので、答えには たどりつける。ただ、ヒントの ことばは「きんいろだよ」（色だけ）。5えん・50えんは どちらも あなが あり、明るさの差は 1.32:1 しかない。色の見え方が ちがう生徒には しぼれない
   - 案: 設計書どおり `dim: [50, 10]` にする
   - 50えんを のこして「えらぶ」ことを わざと残すなら、lesson-designer が設計書を直す。そのうえで ヒントに 色いがいの手がかりを足す（`mark: 'num'`、ことば「きんいろで 5と かいてあるよ」）
3. **【art-director】`style.css` のトレーの緑 `#6E8F7A`**
   - 紙色の文字が 3.29:1 で、チームの基準 4.5:1 に たりない。1280 では「おへや」の名前が 見た目 18.7px になり、大きい文字の境目 ぎりぎり
   - 案: 緑を `#557562`（4.70:1）か `#4F6F5B`（5.14:1）にする。または「おへや」の名前と「いま／えん」を、合計の数字と同じように 紙の札に 墨の文字で のせる
   - `design.md` 52行の説明も あわせて直す
4. **【game-builder】`game.js` `renderTray()` 584行 `slots = Math.max(ans[v], n)`**
   - おおく のせたままヒントが出ると、点線のまるが すべて うまる。そのため「まるの ところに のせよう」の まるが 見えず、どれが おおいかも わからない
   - 案: まるは `ans[v]` こだけ出す。それより おおい硬貨は、まるの外に 少し はなして ならべ、「もどす」しるしをつける（しるしの見た目は art-director）
   - あわせて、ヒントの文は「ちょっと おおいね。1まい もどしてみよう」と ヒントの ことばを つなげず、2つまでにする（`pay()` 657行）
5. **【art-director】`style.css` `--focus-ring`（52行）**
   - フォーカスの わく（紙色6px＋藍12px）が、ヒントの `.hint-frame`（紙色8px＋藍16px）と ほぼ同じに見える。キーボードで硬貨に移ると「ヒントが出た」ように見える。ヒントの わくが ついた硬貨では、フォーカスが どこか わからない
   - 案: フォーカスは 山吹の太い点線 `outline`（`outline-offset` つき）など、形の ちがうものにする
6. **【game-builder】`game.js` `startQuestion()` 825〜828行**
   - ステップ1で「つぎへ」を押すと、そのボタンが かくれて フォーカスが body に落ちる。次の問いの硬貨まで Tab を 6〜8回 押すことになる
   - 案: 「つぎへ」「やってみる」を押して問題に入ったときは、はり紙の「よむ」か 1まいめの硬貨に フォーカスを移す。数字キー 1〜4 で えらべることも、画面か よむボタンで 伝える
7. **【art-director】`style.css` 大きいボタンの高さ 172px**
   - `design.md` は「縮めても 120px 以上」とある。しかし 1280×720 では 115px になる
   - 案: 高さを 180px 以上にする。設定ボタン（1280で 85×83）、ことば欄の「よむ」（88）、トレーの硬貨（80〜88）も 1280 では 120 に とどかない。直すかどうか チームで決める（WCAG の 44px は 満たしている）
8. **【sound-maker】`bgm.js` 111行 `ctx.createDelay(1.0)`**
   - こだまの長さ `EIGHTH*3` が 1.023秒で、上限 1.0秒を こえる。毎回 warning が出て、1.0秒に 切りつめられる
   - 案: `ctx.createDelay(2.0)` にする
9. **【game-builder】`game.js` の ことば（小さい点）**
   - `words.full`「もう のせられないよ。…」は否定の形。案:「これで いっぱいだよ。おかねを おすと もどるよ」
   - ふり返りの1つめ「…100えんの おかね／が わかったね」は、助詞の「が」だけが次の行に落ちる。案: `items[0].text` を「1えん・5えん・10えん・50えん・100えんの\nおかねが わかったね」にする
