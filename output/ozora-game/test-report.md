## 直すべき点（×）
1. **ことばの途中で行が変わる**（担当: art-director／style.css）
   文は分かち書きなのに、行の変わり目が スペースの位置 にならない。例: 「{気持|きも} / ちに」（ステップ1 クリア）、「いか / ない」（ステップ1 もんだい1 の選択肢）、「あっ / たね」（ほめことば）、「わりこん / で きた」（ステップ2 もんだい5）、「い / っしょに 行く」「くわし / く 聞く」「言わ / れた」（ステップ3 もんだい5）、「わらっ / て いる」（ステップ3 もんだい1）、「スルー / は」（説明画面）、「大空 / に とべるよ」（ふり返り）。読むのが苦手な生徒には読みにくい。
   直し方の例: `.stage` に `word-break: keep-all; overflow-wrap: anywhere;` をつけ、スペースの位置で行が変わるようにする。直したら同じ画面を撮り直して確かめる。

## 直すとよい点（○のままでよいが、次に直せるなら）
2. （game-builder）ステップ3で2回目にまちがえると、押したカードが しぼりこみで「押せない」状態になるが、フォーカスが そのカードに残る。キーボードで遊ぶとき、残っている選択肢か「よむ」ボタンにフォーカスを移すとよい。また、しぼりこんだカードに「もういちど」の札が残るので、外すとわかりやすい。
3. （art-director）おてほん画面の「おてほん」テープが 問題文のふりがな（みず など）に 少しかかる。テープを 10px ほど上げるとよい。
