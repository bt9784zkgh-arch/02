# せんたくの めいきゅう

サブタイトル: 3（さん）びょうごの みらいを かえる

## もとの資料
ユーザーの依頼文「選択の迷宮 ― 3秒後の未来を変える」（EQ教材）。人生のいろいろな場面で、選択によって3秒後・1日後・1週間後の未来が変わり、「今の選択 → その後の気持ち → 相手の反応 → 次の問題」の形で行動の結果を体験するゲームの案と、例「宿題を忘れた」（選択A〜Dの4つ）が書かれている。

- 対象: 中学生（特別支援学級）
- ホーム画面: `assets/img/home.jpg`（1530×860、分かれ道の上に立つ子ども。左が紺色・右が赤のじゅうたん模様、中央が金色に光るX字の道）

## このゲームのしくみ（正解当てではない）
- EQ（気持ちの学び）のゲーム。**どの道を選んでも ×（バツ）にしない**。選んだ道の未来を「みる」ことが中心。
- 1場面の流れ
  1. 場面（ばめん）の絵と説明（2文）
  2. **3びょう まって かんがえよう**（いきを すう → はく の円がゆっくり大きく・小さくなる。待つだけで、時間切れではない。「つぎへ」ボタンで進める）
  3. 4つの道（選択肢カード）から1つ選ぶ
  4. 未来のタイムライン: 3びょうご → 1にちご → 1しゅうかんご を1枚ずつ見る。各カードに「きもち（顔の絵）／あいての はんのう／つぎの もんだい」
  5. 「ほかの みちも みてみる？」→ 「みる」で別の道へ、「つぎへ」でまとめの問いへ（1つ見たら進める。全部見なくてよい）
  6. まとめの問い「いちばん みらいが あかるく なりそうなのは どれ？」（おすすめの道 = 自分で解決に向けて動く道）
- **みらいの ランプ**: 各未来カードの右上に金色のランプを1〜3こ表示する（1しゅうかんごの明るさの目安）。点数ではなく、未来を比べるための目じるし。合計・ランキングはしない。
- どの場面も4つの道は同じならび（くりかえしで覚えられるようにする）
  - A: その場の気持ちのまま動く（うそ・ごまかす・どなる など）
  - B: 正直（しょうじき）に つたえる
  - C: なにも いわずに にげる・がまんする
  - D: **おすすめの道** 3びょう まって、解決（かいけつ）に むけて うごく
  - 画面上ではカードの並び順を場面ごとに入れかえてよい（Dがいつも同じ位置にならないように）。色で答えが分からないよう、**4枚とも同じ枠色**にする。

## 学習目標（3個）
1. 行動（こうどう）する前に、「3びょう」まって かんがえることが できる
2. 選（えら）んだ あとの 自分の 気持（きも）ちと 相手（あいて）の 反応（はんのう）を 想像（そうぞう）できる
3. 困（こま）ったときに、正直（しょうじき）に つたえて 解決（かいけつ）に むけて うごく 道を 選ぶことが できる

## ステップ
各ステップの最初に「おてほん」を1回見せる。おてほんは、案内役（あんないやく）の金色の光の玉「ひかりさん」（仮）が操作して見せる。

### ステップ1（やさしい）: 自分のこと・いえのこと（2場面）
- おてほん: 場面1-1を使い、ひかりさんが「3びょう まって かんがえよう」の円にあわせて「すって… はいて…」と言う → カードDを指さして選ぶ → 3枚の未来カードを1枚ずつめくる → 「ほかの みちも みてみる？」でAを選んで未来を見せる → 2つの1しゅうかんごカードを横にならべ「ランプの かずを くらべよう」と見せる。ことば: 「みちを えらぶと、みらいが みえるよ」「どの みちを えらんでも だいじょうぶ」
- 見通し表示: 「ステップ1 ばめん 1/2」

### ステップ2（ふつう）: ともだち・部活のこと（3場面）
- おてほん: ひかりさんが場面2-1の4枚のカードを見せ、「あいての かおにも ちゅうもく しよう」と言って、未来カードの「あいての はんのう」の絵を指さす。
- 見通し表示: 「ステップ2 ばめん 1/3」

### ステップ3（ちょっとむずかしい）: 気持ちが強く動くとき（2場面）
- おてほん: ひかりさんが「かっと したら、まず 3びょう」と言い、円にあわせて深呼吸を一緒にする → 気持ちに名前をつける見本「いま ぼくは くやしい」 → それから道を選ぶ。

## 注意点
- **資料にあるのは例「宿題を忘れた」の1場面（選択A〜Dの方向）だけ**。場面1-1の未来文は依頼の説明（一時的に逃れられるが後から困る／注意されるが解決につながる／問題が残る／自分で解決に向けて動く）を元に具体化した。ほかの6場面、全未来文、相手のセリフはすべて教え方担当が作った案。担任・特別支援の先生による確認が必要（**要確認**）。
- 依頼の表現にそろえ、未来は「〜かも」「〜そう」と可能性の言い方にした。現実にはいつもこの通りになるとは限らない、と先生が補足できるとよい。
- 「みらいの ランプ」は比べるための目じるしで、点数・合計・ランキングにはしない。A〜Cも「ダメな道」として描かない（ランプ1も明かりはつける）。
- カード色でおすすめの道が分からないよう、4枚とも同じ枠にする。並び順は場面ごとに変えてよい（game-builderが決める）。
- 場面3-2（メッセージでからかわれた）は、実際にいじめ・ネットトラブルを経験した生徒にはつらい可能性がある。事前に先生が内容を確認し、必要なら外せるようにする（場面の選択／スキップ機能を推奨）。ゲームの中では「おとなに そうだん する」を必ず肯定し、ゲーム後に先生が声をかけられるようにする。
- 場面1-2（コップを割った）は、かけらを素手でさわらない絵にする（ほうき・ちりとり、おとなといっしょ）。
- 場面3-1・3-2の道Aは、暴力的にならない表現（物を投げる・強い言葉）にとどめ、人をたたく絵は描かない。
- 「3びょう まって かんがえよう」は待つ時間の練習であり、時間制限ではない。カウントは表示しても、0になっても何も起きない。「つぎへ」で自分のペースで進める。「うごきを へらす」設定では円は動かさず、静止した円と「すって」「はいて」の文字だけにする。
- 「深呼吸・気持ちに名前をつける・相手の気持ちを想像する」は一般的な声かけとして入れた。効果についての専門的な説明・数字は入れていない。
- 主人公は性別を決めない描き方にする（セリフは「じぶん」「ぼく／わたし」を使わない）。
- 学校の部活・スマホの有無は生徒によってちがう。合わない場面は先生が外せると安心。
- 1場面は道を1つ見るだけなら約1分、2〜3つ見ると2〜3分。1ステップは2〜3場面で、長くなりすぎないよう「ほかの みちも みてみる？」は任意にしている。
