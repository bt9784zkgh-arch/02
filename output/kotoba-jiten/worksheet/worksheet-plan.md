# ことばの じてん ワークシート（設計書）

> ふりがなの書き方: `{漢字|かんじ}` の形（例: `{大切|たいせつ}`）。生徒が見る文は、漢字に すべて ふりがなを つけています。文は ことばのまとまりごとに半角スペースで区切っています（分かち書き。印刷でもスペースを残す）。「絵」「位置」「メモ」の列と、先生・デザイン担当向けの説明には ふりがなを つけていません。
> 絵の名前は `assets/motifs.js`（design.md 8章）のスプライト名 `m-xxx`。「主＋小」の2つまで（ゲームのカードと同じ組み合わせ）。

## もとの資料
ゲーム「ことばの じてんを つくろう」の学習設計書（`../lesson-plan.md`）と、ゲームの最新の文（`../game.js` の `const LESSON`。チェック後に直した文）。カードの文・ばめんの文・ヒントの文は、すべて `LESSON` からそのまま取った。新しく作ったのは、ワークシートの指示の文・ふり返りの顔の言葉・もんだい4の書く形だけ。

## 学習目標（ゲームと同じ。1まいで3つを ふり返る）
1. その {言葉|ことば}の {意味|いみ}を、{身近|みぢか}な {行動|こうどう}の {例|れい}と むすびつけて わかる ことが できる（はじめに・もんだい1）
2. {合|あ}う {行動|こうどう}を {見|み}つけて、ばめんと {行動|こうどう}を むすぶ ことが できる（もんだい1・2）
3. 「{自分|じぶん}なら どうするか」を {選|えら}び、{自分|じぶん}の {行動|こうどう}を 1つ {表|あらわ}す ことが できる（もんだい3・4）

## 1. 8まい共通の形

### 用紙と使い方
- A4たて・表だけ。1つの言葉につき1まい × 8まい（ステージ1〜8）。
- ゲームの1ステージを遊んだ **あと**（おすすめ。ふり返り）か **前**（予告）に使う。授業10分ほど。
- 問題は **もんだい1〜4 の4こ**（スモールステップ: やさしい → むずかしい）。その前に「はじめに」（なぞる・読む）、あとに「おわりに」（顔マーク）がある。この2つは問題ではないので、正解はない。
- 書く欄は **もんだい4の1行だけ**。それ以外は「なぞる」「〇を つける」「線で むすぶ」だけでできる。

- 余白: 上下左右 12mm。合計 270mm 前後。入りきらないときは、絵を少し小さくする（主 18mm → 16mm）。**問題をへらしたり、字を小さくしたりはしない**。
- 字の大きさ: 指示の文 16pt（太）、カード・ばめんの文 13pt 以上、ふりがな 7pt 以上（本文の0.5倍・design.md 3章と同じ）。書体は Zen Maru Gothic（本文）・Klee One（見出し・なぞる字・心の中のことば）。
- なぞる字: Klee One（教科書体）を うすい灰色の **中ぬき（アウトライン）** か、ごくうすい灰色で。ふりがなは なぞらない（ふつうの こい字で上に出す）。
- 「もんだい1」と「もんだい2」の間に **おりせん**（細い点線・はしに小さく「おりせん」）を入れる。見る量が多いと つらい生徒は、下半分を おって かくし、上から1つずつ取り組める。

### カードの見た目（ゲームとそろえる）
- カード = 紙の色のカード（`--paper`）に、絵（主 18mm＋小 9mm・右下）と文。文は design.md 3章の2行の決まり（12字まで1行。13字以上は分かち書きのスペースで2行）。
- **もんだい1〜3のカードには、なかまの色・形をつけない**（答えが色でばれないように。design.md 6-4「カードの色のルール」と同じ）。なかまの色・形が出るのは「はじめに」と もんだい4のカード（正解のない所）だけ。
- ×のカードも同じ絵の作り方（design.md 8章）。こわい絵・いたい絵にしない。表情は `m-p-worry` まで。
- 小さな記号（先生が答え合わせに使う。灰色・小さく）: もんだい1 は カードの左上に あ〜か（上の段 左から あ・い・う、下の段 え・お・か）。もんだい2 は 左に 1・2・3、右に ア・イ・ウ。もんだい3 は ア・イ・ウ。

### まちがえても大丈夫の作り
- 生徒は「合わない もの」に×を つけない。合う ものを 見つけて〇を つけるだけ。
- 〇の数を先に知らせる（「〇は ぜんぶで 4こ」）。見通しが持てて、おわりが わかる。
- どの問題も、1つめに れい（点線を なぞる）がある（もんだい1・2）。もんだい3はゲームのステップ3と同じ形、もんだい4は れいの文がある。
- もんだい4・おわりには正解がない。何を選んでも〇。
- えんぴつで書く（消して直せる）。

## 3. 先生用「こたえ・つかいかたメモ」（A4たて 1まい）

先生向けなので、ふりがなは つけない。上半分が使い方、下半分がこたえの表。

### このシートの ねらい
- ゲームで集めた例を、紙の上でもう一度見て、「合う行動を見つける → 場面と行動をむすぶ → 自分ならどうするか選ぶ → 自分のことを1つ表す」と、少しずつむずかしくして ふり返る。
- ゲームと同じカードの文・絵を使っているので、「ゲームで見た」と思い出しながら取り組める（くりかえし）。

### 使うタイミング（どちらでもよい）
- **ゲームのあと（おすすめ）**: その日のステージのふり返り。もんだい1〜3は、ゲームで出たカード・場面と同じ。
- **ゲームの前**: 予告として。「はじめに」だけ一緒に読み、もんだいはゲームのあとにしてもよい。

### 10分の流れ（目安）
| 時間 | 欄 | 先生の声かけの例 |
|---|---|---|
| 1分 | はじめに | 言葉といみを先生が読む → 生徒がなぞる。3つのなかまを指さして確認。 |
| 2分 | もんだい1 | 「〇は4こ。1こはもう れいで ついています。あと3こ」 |
| 2分 | もんだい2 | 「1は点線をなぞるだけ。2と3を むすぼう」 |
| 2分 | もんだい3 | 場面の文を読む。「自分なら どうする？」 |
| 2分 | もんだい4 | 「書いても、下のカードを写しても、〇だけでも いい」 |

### 支援のしかた
- **読む**: 文はすべて先生が読み上げてよい（ゲームの読み上げと同じ）。生徒が指で文をなぞりながら聞くとよい。
- **答え方は自由**: 〇・線が書きにくい生徒は、指さし・口で言う・シールをはる でもよい。先生が代わりに書いてよい。
- **見る量をへらす**: 「おりせん」で下半分をおって、上から1つずつ取り組む。もんだいごとに紙で他をかくしてもよい。
- **まちがえたとき（ゲームと同じ3だんかい）**:
  1. 1回目「もういちど 見てみよう」
  2. 2回目 ヒントを読む／絵を指さす（もんだい1は「はじめに」のいみとなかまの絵、もんだい2は下の表の「ゲームのヒント」、もんだい3は紙に書いたヒント）
  3. 3回目 先生が答えを指さし「一緒に たしかめよう」。生徒がそこに〇を書く（これも〇として数える）。
- ×のカードに〇をつけたときも、×は書かない。えんぴつで消して直せばよい。「どうして そう思った？」と聞くと、生徒なりの理由があることがある（例: 場面によっては合うと考えた）。理由が言えたら それもほめる。

### 丸つけのしかた
- 合っている所に〇（朱色）だけをつける。×・点数は書かない。
- もんだい4・おわりには正解がないので、書いたら〇、選んだら〇。
- さいごに「先生から」のわくに はんこ（`stamp-dekita` / `stamp-maru` と同じ図案が使える）。ほめるときは具体的に（「パスを つなぐ に気づけたね」）。

### 配慮が必要な所（lesson-plan の注意点と同じ）
- **ステージ5（申し訳ない）**: もんだい4は「何が あったかは 書かなくて いい」と紙にも書いてある。失敗の内容を発表させない。自分を責めやすい生徒には「して みたい」の方をすすめる。
- **ステージ8（信頼する）**: もんだい3は ネットの安全の場面。家の人に相談しにくい生徒には「先生」「信頼できる大人」と言いかえてよい（口で言いかえる。紙の文を直すなら「{先生|せんせい}や {家|いえ}の {人|ひと}に {相談|そうだん}する」）。学校・家庭のSNSのきまりに合わせて声かけする。
- **家庭のちがい**: 「家のごみ出し」「洗濯物」「家の人に『ごはん ありがとう』」「夕ごはんの準備」など、家庭によってなじみが違う。つらそうなら学校の場面のカードを選ばせる。
- **スマホ・LINE**: 持っていない生徒は「もし持っていたら」で考える。「LINE」は「メッセージ」と読みかえてよい。
- **もんだい4・おわり**: 書いた内容・顔の〇を、みんなの前で比べない。発表は希望者だけ。「もっと 知りたい」に〇をつけた生徒は、ゲームのじてんで もう一度カードを見る時間をとるとよい。

## 4. デザイン担当（art-director）へ
- 8まいは **同じテンプレート** にし、ちがう所（本の色・言葉・いみ・なかま・カード）だけ差しかえる。差しかえ用の中身は 2章の表。

- もんだい2の左右の箱は、左＝ばめん（うすい本の色の面）、右＝行動（紙の色のカード）と見た目を変え、点（・）を向かい合わせに置く。れいの線は点線で、1の点から正しい ア〜ウ の点まで。
- なぞる字・おりせん・顔マーク・先生のわくは新しく作る部品。顔は既存の `m-p-smile`／`m-p-student`／`m-p-student`＋`m-question` を丸わくに入れる形でよい（新しい絵を作るなら、3つとも おだやかな顔に）。

## 注意点
- **資料にない情報を足していないか**: カード・ばめん・ヒントの文は、すべて game.js の `LESSON`（最新）からそのまま写した。言いかえ・付け足しはしていない。新しく作った文は、指示の文（「合う カードに 〇を つけよう」など）、もんだい4の書き方、顔マークの3つの言葉、ステージ5の「何が あったかは 書かなくて いい」、ステージ3の「点線の 雲は 心の 中の ことば」だけ。
- **ゲームとのちがい（要確認）**:
  - もんだい2の「行動」は、ゲームのステップ3の正解の文（`okText` があるものはそちら）を使った。ばめんとセットで出る文なので、ゲームでの見え方と同じ。
  - ステージ3のもんだい1は、×のカードに「心の中のことば」（雲）がないため、6まいとも雲をつけない。雲は「はじめに」の見本と、もんだい3の場面（ゲームのおてほんと同じ「集中したい」）、もんだい4のカードで見せる。
